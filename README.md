# THULAGANYO VINOLIA MARUMO - VIRTUAL CV

This is my personal portfolio website (Virtual CV), built to showcase my education, skills, and academic projects as a final-year BSc Information Technology student at North-West University.

- **index.html** — the page content and structure
- **style.css** — all the styling and colors
